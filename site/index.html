Built for developers and their agents

Set everything in PHP and check it on the shell. The admin keeps only the decisions a site owner makes.

  • Code wins over the admin

    One filter sets any setting, and the admin marks each field that code sets.

  • Agents work on the shell

    WP-CLI shows an agent every service and each setting with its source, so it can check its own work.

  • Prompts built in

    The admin copies a prompt to style the banner, and the page scan writes one for the services it finds.

add_action( 'silvertrail_register', function () {
	silvertrail_register_service( 'google-tag-manager', [
		'tag_id' => 'GTM-XXXXXXX',
	] );
} );

add_filter( 'silvertrail_settings', function ( $settings ) {
	$settings['expiry_months'] = 12;
	return $settings;
} );

One call turns on the preset, and the official tag waits for consent.

<!-- Runs only after the visitor agrees to HubSpot -->
<script type="text/plain" data-silvertrail="hubspot"
	src="https://js.hs-scripts.com/123.js"></script>

Mark any script, and Silvertrail runs it after consent, in its original order.

$ wp silvertrail settings
+---------------+---------+---------+
| key           | value   | source  |
+---------------+---------+---------+
| enabled       | true    | default |
| layout        | "box"   | admin   |
| expiry_months | 12      | code    |
| records       | false   | default |
+---------------+---------+---------+

$ wp silvertrail validate
Success: The config is valid: 5 services.

Every value shows where it comes from: code, the admin or the default.

Batteries included

The integrations most sites need are built in, so setting it up mostly means ticking boxes.

  • WP Consent API

    Plugins that read the API follow the visitor’s choice.

  • Google Consent Mode v2

    The default is set before any Google tag, and every choice updates it.

  • Embed blocking

    YouTube, Vimeo and Google Maps wait behind a placeholder until the visitor allows them.

  • Script detection

    A scan of any page shows what it loads from other servers before the visitor agrees, and suggests a fix for each.

Also in the box

  • Ships presets for Google, LinkedIn and Meta tags
  • Works behind any page cache
  • Honours Global Privacy Control
  • Asks again when services change
  • Keeps optional records without IP addresses
  • Reopens from a link, a block or a floating button
  • Keeps one cookie per site on multisite
  • Adds a few kilobytes of JavaScript and no jQuery

The plugin’s README covers every option in detail.
